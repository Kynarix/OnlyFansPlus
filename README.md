# OnlyFans+

## Özellikler

- İsme göre içerik üreticisi arama
- Favoriler ve geçmiş aramalar (kalıcı)
- Bir üreticinin tüm gönderilerini otomatik yükleme
- Görsel ve video önizleme
- Çoklu seçim ile toplu indirme
- Her dosya için ayrı canlı ilerleme çubuğu, hız ve ETA
- İndirme klasörü, eşzamanlı iş parçacığı sayısı, istek gecikmesi ve içerik türü (görsel/video) ayarları
- Zaman sınırlı video bağlantıları indirme anında taze alınır
- Windows uyumlu dosya adları, kırılan bağlantılarda yeniden deneme ve kaldığı yerden devam

## Kurulum

```bash
pip install -r requirements.txt
python run.py
```

## Notlar

Siteyi aşırı yormamak adına istekler arasında ayarlanabilir bir gecikme uygulanır.
